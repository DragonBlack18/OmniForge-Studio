# OmniForge Studio v0.6.0 — Workspace IDE

## Escopo real

Esta versão complementa o editor Monaco: busca literal em arquivos do workspace, resultados com linha/coluna reais, navegação ao editor e criação segura de pastas e arquivos. Não substitui o grafo de automações, CAD 2D, Git ou agendamentos.

O menu **Buscar em arquivos** e o atalho **Ctrl+Shift+F** abrem a busca. A seleção de um resultado abre o arquivo no Monaco e posiciona o cursor. O painel Arquivos permite **Novo arquivo** ou **Nova pasta**, com caminho relativo; um novo arquivo começa vazio e utiliza o mecanismo existente de revisão SHA-256 antes do primeiro save.

## Restrições da busca

A busca é literal, sem regex fornecida pelo usuário, sem índice persistente, sem acesso de rede e sem logs de conteúdo.

| Limite | Quantidade |
|---|---:|
| Arquivos candidatos | 1.800 |
| Arquivo individual | 320 KB |
| Total lido | 12 MB |
| Ocorrências | 160 |
| Por arquivo | 8 |
| Profundidade | 8 |
| Prazo máximo por pesquisa | 7 segundos |
| Termo | 2–120 caracteres |

A interface exibe aviso de resultados incompletos quando alguma cota é atingida. São ignorados diretórios de dependências, build/cache, .git, .omniforge, arquivos binários, .env*, .npmrc, credenciais comuns e arquivos UTF-8 inválidos. Symlinks/junctions não são seguidos. A implementação não interpreta .gitignore nem pesquisa formatos binários/UTF-16.

## Contrato de criação

Operações de criação são explícitas e individuais, nunca fazem overwrite ou limpeza:

- Caminhos relativos somente, com barras /, no máximo nove segmentos, sem travessia.
- Rejeita nomes Windows reservados, diretórios técnicos e caracteres não permitidos.
- Cada pasta pai deve existir, ser um diretório real e permanecer dentro do workspace.
- Arquivos são abertos no modo wx (exclusive create). Se existem, a ação falha.
- Pastas são criadas por mkdir sem recursive. Se existem, a ação falha.
- Salvar segue o mecanismo já existente de conflito por SHA-256, sem sobrescrita externa silenciosa.
- Sem delete, rename, terminal ou execução arbitrária nesta versão.

O renderer só acessa os três novos métodos autorizados do preload. As criações são serializadas com operações privilegiadas do Electron. A busca ocorre no processo principal com trava contra duas pesquisas simultâneas.

## Testes e gates

Validação exigida: testes Node Linux/Windows; build Vite; smoke Electron real de busca, clique e cursor Monaco, criação e save; regressões das automações, CAD, extensões, scheduler e Git; empacotamento Windows Setup/Portable; instalação/remoção e hashes SHA-256. Falha em qualquer etapa bloqueia integração e release.

## Limites operacionais e segurança

A busca não é um snapshot transacional: alterações externas durante a varredura podem gerar resultados obsoletos, mas o editor verifica revisão ao salvar. Verificações lstat/realpath não eliminam todos os ataques de corrida em diretórios modificados por processo hostil. A funcionalidade é destinada a workspaces locais confiáveis, não a um host de código não confiável ou sandbox multiusuário.
