# OmniForge Studio v0.2.2 — Importação CAD DXF ASCII 2D

**Estado:** funcionalidade desenvolvida em branch empilhada sobre v0.2.1. Não classificar como release até os testes oficiais passarem.

## Escopo implementado

- Importar arquivo .dxf real pelo seletor nativo Electron, sem execução de scripts externos nem leitura de caminhos passados pelo renderer.
- DXF ASCII/UTF-8 até 2 MB. Parser original, restrito a LINE, CIRCLE e LWPOLYLINE sem bulge, largura ou extrusão; linhas e círculos viram entidades do CAD atual e polilinhas retas se tornam segmentos de linha.
- Leitura de camadas, cores ACI/true-color, visibilidade e bloqueio. Camadas declaradas mas vazias são preservadas.
- Respeita INSUNITS: mm, polegadas, pés, cm e metros; as distâncias são normalizadas para mm.
- DXF R12 com unidades ausentes exige confirmação explícita no diálogo nativo para interpretar em mm. MEASUREMENT=1 não equivale a mm.
- Importação altera apenas o buffer de desenho, adiciona uma etapa de Undo, marca como não salvo e ajusta a câmera ao desenho. O usuário deve clicar em Salvar desenho. A gravação com SHA-256 e histórico de revisões permanecem intactos.
- Cancelar seleção ou confirmação de unidades mantém desenho e arquivos atuais.

## Limites e segurança

- Até 2.000 entidades finais e 32 camadas; coordenadas absolutas de até 1.000.000 mm.
- Rejeita integralmente DWG, ARC, SPLINE, DIMENSION, INSERT/BLOCK, geometrias 3D, bulges, espessuras, unidades não suportadas, DXF corrompido/truncado e arquivos binários. **Não existe importação silenciosa parcial.**
- O renderer somente chama a ação allowlisted importCadDxf; o processo principal escolhe o arquivo via diálogo. O adaptador faz lstat, checa symlink, tamanho, extensão, UTF-8 e não escreve nada.
- O parser é puro e utiliza a validação do sketch CAD antes de retornar. Não há integração de código-fonte GPL nem biblioteca CAD de terceiros incluída.
- DXFs em outros encodings devem ser exportados em UTF-8. Polilinhas importadas não se mantêm como entidades paramétricas; viram segmentos.

## Gates de aceitação

1. npm test: round-trip DXF, conversão de unidades, camadas, limite de tamanho, rejeição de entidades desconhecidas, arquivo real sem escrita e symlink.
2. npm run build: compilação React/Vite.
3. npm run smoke:cad-import: Electron real com chooser nativo, importação em memória, save/reload, rejeição de ARC, confirmação e cancelamento de unidades.
4. Integração em main somente após v0.2.1 aprovada e testes oficiais de v0.2.2 aprovados.
